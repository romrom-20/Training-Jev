# Data attribution

MAMS-ATSA is from the authors' [MAMS-for-ABSA repository](https://github.com/siat-nlp/MAMS-for-ABSA),
associated with Jiang et al., [A Challenge Dataset and Effective Models for
Aspect-Based Sentiment Analysis](https://aclanthology.org/D19-1654/), EMNLP-IJCNLP
2019. The upstream repository includes an Apache 2.0 license. This bundle does not
redistribute source sentences.

SemEval-2014 Task 4 restaurant annotations are described on the
[official task page](https://alt.qcri.org/semeval2014/task4/). The local frozen XML
was read from the public mirror documented in the
[prior SemEval bundle](../granite-semeval-margin-generation-v1/DATA_ATTRIBUTION.md).
Consult the task organizers and upstream sources for original data terms. This
bundle includes no source review text.
