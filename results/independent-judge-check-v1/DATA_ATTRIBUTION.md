[official task page](https://alt.qcri.org/semeval2014/task4/). The local frozen XML
was read from the public mirror documented in the
[SemEval score-generation bundle](../granite-semeval-margin-generation-v1/DATA_ATTRIBUTION.md).

bundle contains no source review text or generated completions.
